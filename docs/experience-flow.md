# Experience Flow Specification

## Overview

This document defines the user journey and interaction flow.

The website is an interactive cinematic experience, not a traditional landing page.

---

# Entry Experience

User opens website.

Flow:

1. Initial loading sequence.
2. Background atmosphere appears.
3. Main visual object is revealed.
4. Typography animation starts.
5. User interaction becomes available.


---

# Scene Navigation


## Intro

Purpose:

Create first emotional impression.


Transition:

User interaction triggers movement to Selection scene.



## Selection

Purpose:

Allow users to choose memory experiences.


Navigation:

Card based interaction.



## Journey

Purpose:

Display relationship timeline.



## Gallery

Purpose:

Explore photographs and memories.



## Playlist

Purpose:

Music interaction experience.



## Gift

Purpose:

Reveal surprise content.



## Final Letter

Purpose:

Emotional closing scene.



---

# Interaction Principles

- Every scene must have clear entry and exit states.
- Transitions should feel cinematic.
- Avoid abrupt navigation.
- User should understand current position.
