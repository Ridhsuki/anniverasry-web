# Asset Strategy


## Directory


public/assets/


Structure:

images/
audio/
decorations/
fonts/


---

# Image Rules


Preferred format:

- WebP
- AVIF


Requirements:

- optimized before production
- meaningful filenames
- lazy loaded when possible


---

# Audio Rules


Supported:

- mp3
- optimized bitrate


Audio must support:

- play
- pause
- volume control
- fade transition
